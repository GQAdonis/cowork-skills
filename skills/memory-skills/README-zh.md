# 记忆文件系统

[![CoALA](https://img.shields.io/badge/基于-CoALA-blue)](https://arxiv.org/abs/2309.02427)

> **记忆 = 文件系统** - 语言代理的认知架构

[English](./README.md) | [日本語](./README-ja.md)

## 概述

记忆文件系统是一个 Claude Code 技能，基于普林斯顿大学的 [CoALA 框架](https://arxiv.org/abs/2309.02427)（语言代理认知架构）实现了完整的记忆系统。

## 特性

- **四种记忆类型**：工作记忆、程序性记忆、语义记忆、情景记忆
- **双重作用域**：全局 (`~/.claude/memory/`) 和项目级 (`.claude/memory/`)
- **智能检测**：根据内容类型自动分类记忆
- **反思机制**：将情景经验转化为语义知识
- **遗忘机制**：删除过时或无关的记忆
- **搜索索引**：基于 JSON 的索引实现快速检索

## 安装

```bash
# 安装 cowork CLI
cargo install cowork

# 初始化内置技能
cowork init
```

## 记忆架构

```
                    ┌─────────────────┐
                    │    工作记忆      │  ← 短期
                    └────────┬────────┘
                             │
        ┌────────────────────┼────────────────────┐
        ↓                    ↓                    ↓
┌───────────────┐   ┌───────────────┐   ┌───────────────┐
│   情景记忆     │   │   语义记忆     │   │  程序性记忆    │
│   (经历)      │   │   (知识)       │   │   (方法)      │
└───────────────┘   └───────────────┘   └───────────────┘
```

## 命令

| 命令 | 描述 |
|------|------|
| `/remember <内容>` | 保存到适当的记忆位置 |
| `/recall <主题>` | 搜索并检索记忆 |
| `/forget <主题>` | 删除特定记忆 |
| `/reflect` | 从经历中生成洞察 |
| `/summarize-session` | 保存当前会话摘要 |

## 目录结构

### 全局记忆 (`~/.claude/memory/`)

```
~/.claude/memory/
├── working/                    # 短期会话上下文
├── procedural/                 # 偏好、工作流、提示模板
├── semantic/                   # 学习内容、反思
├── episodic/                   # 错误、解决方案、轨迹
└── index.json                  # 搜索索引
```

### 项目记忆 (`.claude/memory/`)

```
.claude/memory/
├── semantic/                   # 架构、约定、决策
├── episodic/                   # 会话摘要
└── index.json                  # 项目搜索索引
```

## 使用示例

### 记住某事
```
用户："记住：Rust 中使用 thiserror 定义错误类型"
Claude：✓ 已保存到语义记忆 (rust-tips.md)
```

### 回忆信息
```
用户："你知道关于错误处理的内容吗？"
Claude：找到 2 条相关记忆：
  📁 [语义] rust-tips.md → "使用 thiserror..."
  📁 [情景] solutions/2026-01-20-error-fix.md → "通过...修复"
```

### 反思经历
```
用户："/reflect"
Claude：✓ 从 3 条近期经历生成了 1 条反思
        保存到：semantic/reflections/2026-01-25-async-patterns.md
```

## 记忆类型说明

| 类型 | 用途 | 示例 |
|------|------|------|
| **工作记忆** | 当前会话状态 | 活动目标、中间结果 |
| **程序性记忆** | 如何做事 | 用户偏好、工作流 |
| **语义记忆** | 事实和知识 | 技巧、学习内容、反思 |
| **情景记忆** | 过去的经历 | 犯过的错误、解决的问题 |
