# メモリファイルシステム

[![CoALA](https://img.shields.io/badge/基盤-CoALA-blue)](https://arxiv.org/abs/2309.02427)

> **メモリ = ファイルシステム** - 言語エージェントのための認知アーキテクチャ

[English](./README.md) | [中文](./README-zh.md)

## 概要

メモリファイルシステムは、プリンストン大学の [CoALA フレームワーク](https://arxiv.org/abs/2309.02427)（言語エージェントのための認知アーキテクチャ）に基づいて完全なメモリシステムを実装した Claude Code スキルです。

## 特徴

- **4種類のメモリ**：ワーキング、手続き的、意味的、エピソード的
- **デュアルスコープ**：グローバル (`~/.claude/memory/`) とプロジェクト (`.claude/memory/`)
- **スマート検出**：コンテンツタイプによる自動分類
- **リフレクション**：エピソード的経験を意味的知識に変換
- **忘却機能**：古いまたは無関係なメモリを削除
- **検索インデックス**：高速検索のためのJSONベースのインデックス

## インストール

```bash
# cowork CLI をインストール
cargo install cowork

# 組み込みスキルを初期化
cowork init
```

## メモリアーキテクチャ

```
                    ┌─────────────────┐
                    │ ワーキングメモリ │  ← 短期
                    └────────┬────────┘
                             │
        ┌────────────────────┼────────────────────┐
        ↓                    ↓                    ↓
┌───────────────┐   ┌───────────────┐   ┌───────────────┐
│ エピソード的   │   │   意味的      │   │   手続き的    │
│   (経験)      │   │   (知識)      │   │   (方法)      │
└───────────────┘   └───────────────┘   └───────────────┘
```

## コマンド

| コマンド | 説明 |
|---------|------|
| `/remember <内容>` | 適切なメモリ位置に保存 |
| `/recall <トピック>` | メモリを検索して取得 |
| `/forget <トピック>` | 特定のメモリを削除 |
| `/reflect` | 経験から洞察を生成 |
| `/summarize-session` | 現在のセッション要約を保存 |

## ディレクトリ構造

### グローバルメモリ (`~/.claude/memory/`)

```
~/.claude/memory/
├── working/                    # 短期セッションコンテキスト
├── procedural/                 # 設定、ワークフロー、プロンプト
├── semantic/                   # 学習内容、リフレクション
├── episodic/                   # 失敗、解決策、軌跡
└── index.json                  # 検索インデックス
```

### プロジェクトメモリ (`.claude/memory/`)

```
.claude/memory/
├── semantic/                   # アーキテクチャ、規約、決定
├── episodic/                   # セッション要約
└── index.json                  # プロジェクト検索インデックス
```

## 使用例

### 何かを記憶する
```
ユーザー：「覚えておいて：Rustではthiserrorでエラー型を定義する」
Claude：✓ 意味的メモリに保存しました (rust-tips.md)
```

### 情報を思い出す
```
ユーザー：「エラーハンドリングについて何を知っていますか？」
Claude：関連するメモリが2件見つかりました：
  📁 [意味的] rust-tips.md → "thiserrorを使用..."
  📁 [エピソード的] solutions/2026-01-20-error-fix.md → "...で修正"
```

### 経験を振り返る
```
ユーザー："/reflect"
Claude：✓ 最近の3つのエピソードから1つのリフレクションを生成しました
        保存先：semantic/reflections/2026-01-25-async-patterns.md
```

## メモリタイプの説明

| タイプ | 目的 | 例 |
|--------|------|-----|
| **ワーキング** | 現在のセッション状態 | アクティブな目標、中間結果 |
| **手続き的** | やり方 | ユーザー設定、ワークフロー |
| **意味的** | 事実と知識 | ヒント、学習内容、リフレクション |
| **エピソード的** | 過去の経験 | 犯した間違い、解決した問題 |
